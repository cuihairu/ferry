# 套餐与成本设计

目标：节点套餐（带宽/流量/限速）与成本（计费方式/单价/月固定）进元数据与分配决策，成本手录为准、参考库只做提示；账目可算、看板可看、告警可切流。对应 todo E-1/E-8/E-9/E-31/E-32 与 E-21..E-23。

## 1. 套餐元数据

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `bw_up_mbps` / `bw_down_mbps` | **是** | 套餐上下行带宽（Mbps），国内 3M/5M 小带宽必须如实填 |
| `monthly_traffic_quota` | 否 | 月流量配额（字节，0=不限） |
| `rate_limited` | 是 | 是否限速 |
| `burst` | 否 | 是否峰值突发 |
| `speed_measured_mbps` / `speed_calibrated_at` | 系统 | 测速校准实测容量与时间 |

### 1.1 测速校准

```
agent 注册(hello)
   → 注册成功后排队一次轻量测速（下载探针，限时限量，不占满带宽）
   → 实测容量 vs 套餐上报值
        ├─ 偏差 ≤ ±30%：以套餐值为容量基准
        └─ 偏差 > ±30%：以实测为准，记 speed_measured_mbps / speed_calibrated_at
   → 心跳带宽利用率 = 实测吞吐 / 校准后容量
```

- 分配的容量权重分母、利用率分母均取校准后容量——3M 小水管按容量少分连接，不灌爆。

## 2. 计费口径矩阵

| 计费方式（`billing_type`，必填） | 成本优先判定 | 流量成本告警 | 成本看板 |
| --- | --- | --- | --- |
| 按流量 | ✅ 参与 | ✅ 参与 | 花费=当月计费流量 × 单价 |
| 包月 | ❌ | ❌ | 月固定成本入汇总 |
| 固定带宽 | ❌（即包月口径） | ❌ | 月固定成本入汇总 |

- 单价 `traffic_price_cents`（分/GB）、月固定 `monthly_cost_cents`（分/月）、币种 `currency`（默认 CNY）、备注 `cost_note`——**手录为准**。
- **手录价是分配与看板的唯一权威来源**；参考库（§4）只做提示，永不自动改价。

## 3. 成本计算与看板

```
节点花费（月） = 按流量: 计费流量×单价   |  包月/固定带宽: monthly_cost_cents
维度汇总      = 区域 × ISP 两个维度合计
月度预估      = 当前流量 / 已过天数 × 当月天数（按流量计费节点）+ 固定成本
```

- dash 成本看板：节点花费榜、区域/运营商汇总、月度预估；
- 高成本告警：按流量计费节点当月预估费用超阈值 → 面板告警提示切流（经 Herald，按节点单发）；
- 与落地分配联动：成本档进权重（三档：成本优先/性能优先/均衡），仅按流量计费节点参与成本档。

## 4. 成本参考库（插件位，P2）

### 4.1 接口

```go
// packages/costref —— 参考价来源插件
type Source interface {
    Name() string // infracost / pricelist / manual_watch
    // Lookup 按机型/区域/配置查参考牌价（月付价与流量单价）。
    Lookup(ctx context.Context, q Query) (Quote, error)
}

type Query struct {
    Provider string // 云厂商/商家
    Region   string
    Spec     string // 机型配置（CPU/内存/带宽/流量）
}

type Quote struct {
    MonthlyCents int64  // 月付牌价
    TrafficPrice int64  // 流量单价（分/GB），无则 0
    Currency     string
    URL          string // 价格页，可点开核对
    At           time.Time
}
```

### 4.2 来源与提醒

| 来源 | 内容 | 形态 |
| --- | --- | --- |
| 海外牌价 | infracost 类开源价格库 / 公开价格表 | 定期拉取，缓存快照 |
| 国内价格页 | 关注列表的价格页变动 | 周期比对，变动进 dash |

- **促销关注**：dash 设关注条件（机房 / 配置 / 价位），参考库命中降价或促销 → dash 通知（经 Herald）；条件存 `price_watches`。
- 参考价 vs 手录价偏差大 → 节点卡上提示「手录价偏离牌价」，人工复核。

```sql
-- 价格关注与快照（已落地 2026-10-08 E-32，GORM AutoMigrate 按此蓝本落表；
-- REFERENCES 级联改应用层——删关注同删快照）
CREATE TABLE price_watches (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    provider TEXT NOT NULL,
    region TEXT NOT NULL,
    spec TEXT NOT NULL,              -- 关注的配置
    target_price INTEGER NOT NULL,   -- 目标价位（分/月），低于即提示
    enabled INTEGER NOT NULL DEFAULT 1,
    created_at DATETIME NOT NULL,
    UNIQUE(provider, region, spec)
);

CREATE TABLE price_snapshots (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    watch_id INTEGER NOT NULL REFERENCES price_watches(id) ON DELETE CASCADE,
    monthly_cents INTEGER NOT NULL,
    source TEXT NOT NULL,            -- infracost/pricelist/…
    url TEXT,
    captured_at DATETIME NOT NULL
);
```

**落地口径（2026-10-08 E-32 价格关注批）**：`price_watches`/`price_snapshots` 经 AutoMigrate 落库（`storage.PriceWatch`/`PriceSnapshot`；快照级联删除走应用层同删）。扫描器 `cost.WatchLoop`（main 装配，`FERRY_PRICE_WATCH_SEC` 缺省 3600，建议小时级——价格不分钟级变）：逐条启用关注从已导入参考价表抓牌价落快照；未导入表整轮 no-op、键不在表内静默跳过等价格表更新。命中两类：**降价**=较上一快照下降（发降幅百分比）；**到位**=`target_price`>0 且现价自上方跨越进目标价内——跨越沿只发一次，到位后维持不重复。告警 `price_alert`（warning/admin，经 Herald 未配落本地 outbox 站内可见），dedup `price_drop:<id>:<日>`/`price_target:<id>:<日>` 本地同日至多一条（与 login_alert 同口径）。键归一（小写+去空格）入 `idx_price_watch` 唯一索引（provider+region+spec），与 costref.Lookup 比对口径一致；重复关注 409。端点：`GET/POST /api/cost/watches`（列表含动态：最新/上次快照、涨跌百分比、到位标记）、`PUT/DELETE /api/cost/watches/:id`（部分更新目标价/开关；删除级联清快照）、`GET /api/cost/watches/:id/snapshots?limit=`（id DESC 上限 100）。dash 成本页「价格关注」卡：条件增删（商家/区域/配置档/目标价元）+动态表（降/涨/到位 tag、待首扫空态）。GORM `TranslateError` 随本批开启（重复键翻译 `gorm.ErrDuplicatedKey`，原先裸驱动错误处仍走 err!=nil 分支无回归）。测试：扫描六态（基线/同价/降价+到位/维持不重复/停用不扫/键缺失跳过）+CRUD 端到端（校验/409/部分更新/快照分页/级联删/动态装配）。

**落地口径（2026-10-08 E-31 参考库批）**：插件位 `packages/costref`（纯 stdlib 独立 module，server 以 replace 引用）——`Source`/`Query`/`Quote` 按本节接口，另落 `Compare`（手录价 vs 牌价偏差百分比，正=手录贵，超容忍度回 `Off`，币种不符/任一侧未填显式报错不硬比）与 `StaticSource`/`ParseTable`（公开价格表形态：JSON 数组导入，导入层拒脏表——缺 provider/spec、月价非正即拒）。**选型判断（开源优先令留档）**：infracost 类开源价格库面向 AWS/GCP/Azure 的 terraform 资源口径、无 VPS/中转商家数据，暂不接库；首形态数据驱动价格表（面板导入维护），后续接真实在线来源=另实现一个 Source（接库前核 license）。server 接线：价格表落 settings 键 `costref_static_table`；三端点 `GET /api/cost/ref`（单点试查：`node_id` 按节点映射=机房→商家/区域/套餐档「下行M-月流量G」+手录月固定成本，或自由键；未命中 200+`hit:false`，币种不符/未填手录回 `reason`）、`GET /api/cost/ref-check`（批量对账：机房+月固定成本齐全节点逐个比对，只列命中可比行含偏差）、`PUT /api/cost/ref-table`（导入/清空）；偏差容忍度 `tolerance_pct` 缺省 ±30%。「手录价偏离牌价」提示面=成本页批量对账表（节点卡内嵌提示随价格扫描批 E-32 一起）；参考价永不回写 nodes 手录价。dash 成本页「成本参考库」卡：价格表导入/批量对账（容差·参查·命中·币种不符计数+偏差表+价格页核对链接）/单点试查。测试：costref 包单测（表校验/命中归一/偏差六面）+handler 端到端（导入校验/试查各面/批量计数）。
