# Glossary (Source Layer Analysis)

> This glossary accompanies the "Source Layer Analysis" and covers only abstract-layer concepts; each entry carries its definition and source reference (`file:line`).
> 中文版：[术语表](/design/术语表)

## Abstract-Layer Concepts

| Term | English | Definition | file:line |
| --- | --- | --- | --- |
| 服务装配层 | Service Assembly | Binary entry point: reads environment config, resolves key gate, opens the database, starts all background loops, and serves HTTP. Layer = responsibility (assembly & lifecycle), not directory name. | `server/cmd/ferry/main.go:68` |
| 配置层 | Config | Central definition and reading of service runtime parameters: env vars (`FERRY_*`) → defaults; two separate schemas for the server and agent sides. | `server/internal/config/config.go:146`；`agent/internal/config/config.go:63` |
| 密钥门禁层 | Key Gate | Initialization of signing/encryption keys: explicit config > key file > generate & persist; production refuses startup on missing/weak keys. | `server/internal/keyinit/keyinit.go:48` |
| 存储层 | Storage | GORM three-dialect (sqlite/postgres/mysql) connection and AutoMigrate; all business state is in the relational DB, no Redis. | `server/internal/storage/storage.go:27` |
| 数据模型层 | Data Model | Domain entities and cross-layer payloads: GORM models (storage/models.go) separate from request/response payloads (model/model.go). | `server/internal/storage/models.go:5`；`server/internal/model/model.go:1` |
| 协议契约层 | Protocol Contract | agent↔panel message contract: WebSocket + JSON envelope, version number, message types, payload structures; shared package. | `packages/agentproto/envelope.go:1`；`packages/agentproto/messages.go:1` |
| 连接枢纽层 | Connection Hub | In-process memory table of online agent connections (map[nodeID]*Conn) + request/reply association (waiters); memory only, not persisted. | `server/internal/agenthub/hub.go:66` |
| HTTP 路由层 | HTTP Routing | gin engine mounts all endpoints, split into auth groups (admin/public/distributor/admin-side), unified middleware chain. | `server/internal/handler/router.go:53` |
| 接口处理器层 | Interface Handler | HTTP handlers per resource: parse payload, validate, call domain service, write back JSON; attached to the Handler struct. | `server/internal/handler/node.go`；`server/internal/handler/panel.go:213` |
| 领域服务层 | Domain Service | HTTP-independent business-logic packages (alloc/pool/monitor/recovery/provision/…): periodic loops + judgment/execution functions. | `server/internal/alloc/alloc.go:395`；`server/internal/pool/pool.go:74` |
| 采集与画像层 | Collection & Profiling | agent heartbeat/traffic/probe/proc-status reports → persisted; node profiling (meta/load/cost/health) driven by reports. | `server/internal/handler/agentws.go:51`；`server/internal/aggregate/aggregate.go:65` |
| 决策与执行层 | Decision & Execution | Landing allocation, entry pool suspend/resume, ban recovery, provisioning/cert/DNS orchestration: read profile → decide → trace → trigger push. | `server/internal/alloc/alloc.go:437`；`server/internal/recovery/recovery.go:107` |
| 下行推送层 | Downstream Push | Panel→agent config push / repoint: persist pending → wait for agenthub ack → mark applied/failed; reuses the config.push chain. | `server/internal/relaypush/relaypush.go:69` |
| 事件外发层 | Event Egress | Event outbox: event persisted and returned immediately, async retry to Herald; without Herald only persisted for in-site visibility; webhook notification slot. | `server/internal/herald/herald.go`；`server/internal/notify/notify.go` |
| 安全与限流层 | Security & Rate Limit | Unified AES-256-GCM secret encryption (R24); in-memory sliding-window rate limit (PAY-5); JWT auth middleware; audit middleware. | `server/internal/secret/secret.go:28`；`server/internal/ratelimit/limiter.go:37`；`server/internal/handler/apitoken.go:92` |
| 运维与恢复层 | Ops & Recovery | Backup (VACUUM INTO+S3 egress), panel master/standby sync, audit sweep, run-log ring buffer, support integration. | `server/internal/backup/backup.go:153`；`server/internal/standby/standby.go:151`；`server/internal/audit/audit.go:30` |
| Agent 核心层 | Agent Core | Agent resident minimal set: connect/heartbeat, proc supervision, config push/rollback, traffic/load reporting (target ≤10MB). | `agent/internal/app/app.go:74`；`agent/internal/link/link.go:62` |
| Agent 角色层 | Agent Role | Standalone process components assembled by node role: probe/relay/speedtest/tunnel; interacts with core only via local config file/spool. | `agent/internal/roles/roles.go:1`；`agent/internal/roles/relay/relay.go:41` |
| 隧道传输层 | Tunnel Transport | Tunnel-plugin abstraction: tls-camo/quic/ws-tls/ssh, outbound Dial + application heartbeat; registry constructs by name. | `agent/internal/tunnel/tunnel.go:16` |
| 订阅渲染层 | Subscription Render | Node config → v2ray/clash(mihomo)/sing-box subscription content; entry order re-sorted by probe RTT + rotation. | `server/internal/sub/links.go`；`server/internal/sub/rotate.go:21` |
| 支付渠道层 | Payment Channel | Payment Provider contract & registry (card/epusdt/wechat/alipay); channel plugins self-register in init, verification inside channel. | `packages/payment/provider.go:13`；`payments/epusdt/epusdt.go:64` |
| 成本参考层 | Cost Reference | Reference-price source plugin slot (costref.Source); manual cost is the sole authority, reference price only hints and never changes price. | `packages/costref/costref.go:25`；`server/internal/cost/ref.go:25` |
| 前端管理面 | Admin Frontend | Vue3 + Element Plus admin console (dash): route-level views + api.ts client (Bearer JWT/distributor token). | `dash/src/router.ts:7`；`dash/src/api.ts:16` |
| 前端用户面 | User Frontend | Vue3 user panel (panel): login/overview/redeem/orders/notifications; api.ts client carries subscription token. | `panel/src/router.ts:5`；`panel/src/api.ts:13` |
