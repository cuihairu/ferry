# 开源选型设计（开源优先令）

口径：**凡成熟开源库/现成引擎能干的一律用现成，不自研轮子**。ferry 选 Go 就为生态；自研只保留两类——领域逻辑（恢复流水线、池调度等无现成件）与有实测尺寸理由的极薄封装。本文记录盘点结论、license 传染性结论与替换推进顺序；每次换件在此留档取舍。

## 1. license 传染性结论（接入前必核）

| 项目 | license | 结论 |
| --- | --- | --- |
| quic-go | MIT | 可安全引依赖（已经 gin 间接在 server 依赖树中） |
| XTLS/Xray-core | MPL-2.0 | 弱 copyleft（文件级）：进程隔离（二进制适配）零传染；import 源码仅改动文件需开源 |
| SagerNet/sing-box | GPL-3.0-or-later | 强 copyleft：**只走二进制适配/进程隔离，不 import 源码** |
| apernet/hysteria2 | AGPL-3.0 | 最强网络 copyleft：**只走二进制适配/进程隔离，不 import 源码** |
| go-acme/lego v4 | MIT | 可安全引依赖 |
| libdns 系列 | MIT（生态约定全宽松） | 可安全引依赖 |
| shirou/gopsutil | MIT | 可安全引依赖 |

进程隔离口径：外部引擎以独立进程运行（面板/agent 只管启停与配置下发），无源码链接即无 copyleft 传染；AGPL 的网络条款也只在"修改后对外提供网络服务"时触发，未修改原样运行不触发。

## 2. E-18b QUIC 三选对比（拍板 2026-10-08：独立 plugin 二进制）

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| 独立 plugin 二进制 | 主仓/agent 尺寸门禁（E-4 10MB）不动；依赖隔离；可换引擎 | 多一个发布件 | ✅ **采用** |
| quic-go 引主仓 | 少一个件 | agent 二进制顶破门禁（server 侧已因 gin 带入，agent 侧无此问题） | 否 |
| 延后 | 零成本 | 丢 QUIC 场景（弱网/移动端） | 否 |

协议口径：**不自研任何协议**——QUIC 基座引 quic-go（MIT）；hysteria2/sing-box/Xray-core 只做二进制适配（进程隔离），不 import 其源码；真 hysteria2 协议不造、raw QUIC 不冒称 hysteria2，文档如实标注。

## 3. 全仓盘点：自研件 → 开源替代对照表

### 3.1 换（已列队）

| 自研件 | 位置 | 现状 | 替换为 | 风险 |
| --- | --- | --- | --- | --- |
| /proc 手解析主机快照（229 行） | `agent/internal/host` | uptime/load/cpu/mem/net/tcp 全手写 | `shirou/gopsutil/v4`（MIT）✅ 已换（agent 7.33MB→7.61MB，+291KB，E-4 门禁余量充足） | 低 |

### 3.2 候选（随相应批次）

| 场景 | 现状 | 用什么 |
| --- | --- | --- |
| 支付渠道实装（PAY 批） | alipay/wechat 占位 8 行 | 现成 SDK（如 smartwalle/alipay，Apache-2.0），不手写签名/回调验签 |
| Xray 内核对接 | agent 侧 `xraystats` 手写 gRPC unary + varint（228 行，E-4 实测省 8.3MB）；server 侧 Noop 接口位 | 引官方 proto + 轻量调用替换手写编解码；引擎本身二进制进程隔离（MPL-2.0 无传染） |
| GeoIP 分流（未来功能） | 无 | MaxMind `geoip2-golang`（Apache-2.0）/ v2ray-geoip dat，不自研 |
| QUIC 传输（E-18b） | 无 | quic-go（MIT）独立 plugin；hysteria2/sing-box 仅二进制适配 |

### 3.3 保留（自研合理，理由留档）

| 件 | 位置 | 保留理由 |
| --- | --- | --- |
| 滑动窗口限流（111 行） | `server/internal/ratelimit` | 失败锁定语义（兑换防爆破）为领域定制；换 x/time/rate 需外拼锁定逻辑反而更多代码，零依赖贴合小内存 |
| 环形日志缓冲（92 行） | `server/internal/ringlog` | io.Writer 环形缓冲无事实标准库；文件轮转类（lumberjack）语义不同 |
| AES-GCM 机密封装（114 行） | `server/internal/secret` | stdlib 惯用法薄封装 + 换钥版本头为领域语义；tink/age 过重 |
| 边缘探测多轮拨号（178 行） | `agent/internal/probe` | 丢包率/晚高峰窗口为领域口径，无现成库贴合；拨号本身用 net 标准库 |
| 卡密生成/配额窗口/订阅拼装/聚合判定/传输判定/分配/池/恢复/成本/复核 | `server/internal/{cardcode,quota,sub,aggregate,transport,alloc,pool,recovery,cost,review}` | 领域逻辑非通用轮子；YAML 用 yaml.v3、无手写编解码 |
| ws-tls 传输插件（147 行） | `agent/internal/tunnel` | gorilla/websocket 薄适配（库承担协议），非协议自研 |

## 4. 推进顺序

1. OSS-1 host → gopsutil（agent 侧，换后复测尺寸）
2. OSS-2 dns → libdns/cloudflare
3. OSS-3 cert → lego
4. E-18b QUIC plugin（quic-go，独立二进制）
5. 其余随批次（支付 SDK 随 PAY、Xray 随内核对接批）

每换一件：测试全绿 → 提交推送 → 本文对照表勾注。
