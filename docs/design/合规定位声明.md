# 合规定位声明

> **ferry 是一个代理集群管理工具，部署与运营的合规责任在部署者。**

## 1. 工具定位

- ferry 提供的是**管理能力**：用户/节点/订阅/流量记账、节点进程与配置管理、分配与告警——面向部署者**自有或已获授权**的服务器资源的运维面板。
- ferry 不提供代理服务本身，不运营任何网络接入，不面向公众提供翻墙/梯子类服务。

## 2. 责任边界

| 方 | 责任 |
| --- | --- |
| 部署者 | 所在司法辖区的法律法规、云服务商服务条款、资源与流量的用途合规、对被管理用户的告知与约束 |
| ferry | 工具本身的功能正确性与安全（Apache-2.0 开源，按 LICENSE 免责条款） |

- 部署者部署与使用该工具即视为知晓并承担上述责任。

## 3. 实现层面的边界

- **不内置默认目标**：分流规则、接入配置由部署者自行配置，工具不预置任何规避审查的默认目标或内容源；
- **不代运营**：一键开服/恢复等能力操作的是部署者自己的云账号与资源（凭证由部署者提供并自行保管）；
- **用户数据最小化**：面板只存管理所需字段（见各设计篇数据模型），对外出口（订阅/公告）不含内部信息。
