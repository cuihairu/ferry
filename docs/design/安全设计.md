# 安全设计

目标：把 ferry 的攻击面逐项定防护口径——面板认证、节点信任链、机密存储、订阅隔离。

## 0. 威胁面总览

```
                     ┌───────────────────────────┐
  管理员 ──登录──→    │ 面板（dash/panel API）      │ ← 2FA/防爆破/审计
  用户   ──订阅──→    │ 订阅端点 /sub/{token}      │ ← 令牌隔离/限频
                     └─────┬─────────────────────┘
                           │ WS（agentproto）
                     ┌─────▼─────────────────────┐
  节点 agent ──────→ │ 节点接入认证                │ ← 节点令牌轮换 + mTLS
                     └───────────────────────────┘
                           │ 供给/恢复
                     ┌─────▼─────────────────────┐
  云 API ──────────→ │ 云密钥存储                  │ ← R24 加密面口径
                     └───────────────────────────┘
```

## 1. 面板认证与管理台（P1）

| 项 | 口径 |
| --- | --- |
| 管理员登录 | 会话或 JWT（对齐 P1-1），密码哈希 bcrypt/argon2id |
| **2FA**（已落地 2026-10-08） | TOTP（对齐 3x-ui 做法）：dash 设置页两步绑定（setup 加密暂存→enable 校验落库），登录二次校验（6 位 TOTP 或恢复码）；恢复码一次性备用 |
| **数据面鉴权**（已落地 2026-10-10） | `/api` 组全量 `apiAuth` 双凭据（`handler/apitoken.go`，此前该组无中间件管理接口公网裸奔）：管理员 JWT（签名秘钥 `FERRY_ADMIN_SECRET`）或 API Token（`POST /api/token` 签发 30 天令牌，秘钥 `FERRY_API_SECRET`）；两秘钥缺省回落仓库常量**仅供本机开发**，公网部署必设随机串（compose/env.example/部署指南三处注记）。自证面挂 `open` 组不经 apiAuth：panel 订阅令牌、bot 服务令牌、Herald 回执 HMAC、epusdt 回调验签 |
| 防爆破 | 登录失败限速（滑动窗口，失败 N 次锁一段时间，对齐 3x-ui login_limiter）；兑换/订阅接口同机制复用 |
| 登录审计（已落地 2026-10-08） | `login_logs`（时间/IP/UA/结果），dash 设置页可查；异地/连续失败告警经 Herald |

```sql
-- login_logs（已落地 2026-10-08，GORM AutoMigrate 按此蓝本落表）：
CREATE TABLE login_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT NOT NULL,
    ip TEXT NOT NULL,
    ua TEXT,
    ok INTEGER NOT NULL,
    created_at DATETIME NOT NULL
);
CREATE INDEX idx_login_logs_time ON login_logs(created_at);
```

**落地口径（2026-10-08 P1 安全批）**：`server/internal/handler/twofa.go`（2FA 四端点 `GET /admin/2fa`、`POST /admin/2fa/{setup,enable,disable}` 与登录二次校验 `checkTwoFA`）与 `loginlog.go`（审计落行/告警/分页），表 `login_logs`/`recovery_codes` 经 AutoMigrate 落库（`storage.LoginLog`/`RecoveryCode`，created_at/user_id 带索引）。TOTP 用 pquerna/otp v1.5.0（Apache-2.0）：30s/6 位/SHA1、±1 周期容差；密钥经 secret_store 加密落 `users.totp_secret`（主密钥未配置时绑定明确拒绝 400，密钥永不明文落库），绑定两步（setup 密钥加密暂存 settings `admin_2fa_pending` → enable 校验一次 TOTP 才落用户行，避免二维码没扫成留半绑定态）。恢复码 8 枚 `xxxx-xxxx`（crypto/rand）只存 sha256，消费 = `UPDATE ... WHERE used_at IS NULL` 条件更新（并发重放只一方成功）。防爆破复用兑换限速（10 次/分钟、失败 5 次锁 15 分钟，按 IP）。登录失败/成功各落一行审计；告警 `login_alert`（warning/admin，经 Herald outbox 未配时落本地站内可见，kind+dedup_key 本地按日至多一条）：连续失败=同 IP 15 分钟窗口 login_logs 失败≥5 行（对齐限速阈值），异网段=与上次成功登录不同网段（v4 /24、v6 /64，首次成功无基线不判）。dash 侧：登录页 `/login` 全页守卫（`totp_required`/`totp_invalid` 机器码驱动验证码输入位，恢复码同框可输）+ 设置页两步验证卡（二维码/密钥串/恢复码一次性展示/密码确认关闭）与登录日志分页卡；管理员首启引导 `FERRY_ADMIN_USER`/`FERRY_ADMIN_PASSWORD`（库内无管理员时启动建号，存在则忽略不覆盖密码——单管理员口径）。路由修复：`POST /admin/login` 此前误挂鉴权组内致登录面 401 永不可达，已移出。

**落地口径（2026-10-10 数据面鉴权批）**：`router.go` `/api` 组挂 `apiAuth`（`apitoken.go:92`，Bearer 双凭据二选一：管理员 JWT 走 `cfg.AdminSecret` 校验且**只认 `is_admin=true`**；API Token 走 `cfg.ApiTokenSecret`，30 天有效、`POST /api/token` 签发，脚本/自动化调用口径见 FAQ「脚本/自动化怎么调管理 API？」）。`/admin` 组同口径只认 `is_admin=true`——代理令牌（DS-1 与管理员同密钥签发、`role=distributor`）签名可验但不得越管理面（2026-10-10 实机走查发现补修，回归 `apiauth_test.go` 两例）；代理自面验签与 `DistributorLogin` 签发同源 `cfg.AdminSecret`（此前硬编码缺省常量，env 配置后自面整面 401）。回归测试 `apiauth_test.go` 九例（无凭据 401/伪 JWT 401/真实 JWT 200/API Token 200/自证面不受影响/代理令牌拒管理面/代理自面认 env 秘钥等）。部署秘钥面：`FERRY_ADMIN_SECRET`/`FERRY_API_SECRET` 已入 compose 透传与 `ferry.env.example`（缺省回落常量仅供本机开发，公网必须随机串——见部署指南「首启前必须看清的几张」表）。

## 2. 节点信任链

### 2.1 节点令牌轮换

- 节点 token = agent 出站连接凭证（必选）；dash 节点页可**轮换**；
- 轮换窗口（未实现）：新旧 token 并行有效（默认 24h），agent 用新 token 重连成功后旧 token 失效——轮换不造成节点掉线；
- 泄露处置：立即轮换 + 可选强制下线（断旧连接）。

### 2.2 mTLS 证书生命周期

```
CA（面板持有）──签发──→ 节点客户端证书（CN=节点ID，有效期可配）
        └──签发──→ 面板服务端证书
到期前 30 天 → cert_expiring 告警（Herald）→ dash 一键续签 → config.push 新证书 → agent 热加载
吊销（未实现）：节点下线/换机 → 吊销列表（CRL 或面板侧校验位）
```

- mTLS 为可开关（对齐 A-2），开启后令牌+mTLS 双因子；CA 私钥只在面板机，签发动作留审计。

## 3. 机密存储（R24 加密面口径）

- **主密钥不入库**：部署环境变量/文件注入（如 `FERRY_SECRET_KEY`），丢失即不可恢复（文档写明备份要求）；
- **落库加密**：云 API 密钥、Herald token、域名商 API 等机密一律 AES-256-GCM 加密落库，密文带版本号支持换钥；
- **不回显**：dash 表单回显掩码（`****`），不回传明文；
- **最小可见**：机密仅 server 进程在执行动作时解密，日志/state/错误信息不落明文；
- alg/密钥版本：`secret_store` 统一入口（`Encrypt/Decrypt`），全项目禁止散落手写 crypto。

## 4. 订阅令牌隔离（P0）

- **sub token ≠ 用户密码**：独立随机 256 位（复用 `randomToken`），泄露只影响订阅可见性，不触及账号管理面；
- 订阅端点只读、可独立重置（重置后旧链接失效）；
- 限频（已落地 2026-10-09）：订阅端点双层——按 token 限频（30 次/分钟滑动窗口，防单 token 爆破）+ 按 IP 未命中锁定（未知/停用令牌连续 20 次锁 15 分钟，防每次换新 token 的枚举，复用兑换限速的失败锁定语义）；命中 429 并记日志（token 脱敏只留前缀 + IP）；此前限速仅兑换/测速/下单三处；
- 最小化：订阅响应不含管理字段（成本/内部 IP 等），只含节点连接信息。

## 5. 其他面

| 面 | 口径 |
| --- | --- |
| 内部接口 | `/api/internal/*` 部署侧以网络边界隔离（当前与公网同引擎单 `FERRY_ADDR` 监听，未强制分绑） |
| servify 上下文 | 只读接口白名单下发（套餐/流量/订单），凭据类字段永不下发（见《用户面板运营设计》§4） |
