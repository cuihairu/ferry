# 安全设计

目标：把 ferry 的攻击面逐项定防护口径——面板认证、节点信任链、机密存储、订阅隔离。

## 0. 威胁面总览

```
                     ┌───────────────────────────┐
  管理员 ──登录──→    │ 面板（dash/panel API）      │ ← 2FA/防爆破/审计
  用户   ──订阅──→    │ 订阅端点 /sub/{token}      │ ← 令牌隔离/限频
                     └─────┬─────────────────────┘
                           │ WS（agentproto）
                     ┌─────▼─────────────────────┐
  节点 agent ──────→ │ 节点接入认证                │ ← 节点令牌轮换 + mTLS
                     └───────────────────────────┘
                           │ 供给/恢复
                     ┌─────▼─────────────────────┐
  云 API ──────────→ │ 云密钥存储                  │ ← R24 加密面口径
                     └───────────────────────────┘
```

## 1. 面板认证与管理台（P1）

| 项 | 口径 |
| --- | --- |
| 管理员登录 | 会话或 JWT（对齐 P1-1），密码哈希 bcrypt/argon2id |
| **2FA** | TOTP（对齐 3x-ui 做法）：dash 设置页绑定，登录二次校验；恢复码一次性备用 |
| 防爆破 | 登录失败限速（滑动窗口，失败 N 次锁一段时间，对齐 3x-ui login_limiter）；兑换/订阅接口同机制复用 |
| 登录审计 | `login_logs`（时间/IP/UA/结果），dash 可查；异地/连续失败告警经 Herald |

```sql
CREATE TABLE login_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT NOT NULL,
    ip TEXT NOT NULL,
    ua TEXT,
    ok INTEGER NOT NULL,
    created_at DATETIME NOT NULL
);
CREATE INDEX idx_login_logs_time ON login_logs(created_at);
```

## 2. 节点信任链

### 2.1 节点令牌轮换

- 节点 token = agent 出站连接凭证（必选）；dash 节点页可**轮换**；
- 轮换窗口：新旧 token 并行有效（默认 24h），agent 用新 token 重连成功后旧 token 失效——轮换不造成节点掉线；
- 泄露处置：立即轮换 + 可选强制下线（断旧连接）。

### 2.2 mTLS 证书生命周期

```
CA（面板持有）──签发──→ 节点客户端证书（CN=节点ID，有效期可配）
        └──签发──→ 面板服务端证书
到期前 30 天 → cert_expiring 告警（Herald）→ dash 一键续签 → config.push 新证书 → agent 热加载
吊销：节点下线/换机 → 吊销列表（CRL 或面板侧校验位）
```

- mTLS 为可开关（对齐 A-2），开启后令牌+mTLS 双因子；CA 私钥只在面板机，签发动作留审计。

## 3. 机密存储（R24 加密面口径）

- **主密钥不入库**：部署环境变量/文件注入（如 `FERRY_SECRET_KEY`），丢失即不可恢复（文档写明备份要求）；
- **落库加密**：云 API 密钥、Herald token、域名商 API 等机密一律 AES-256-GCM 加密落库，密文带版本号支持换钥；
- **不回显**：dash 表单回显掩码（`****`），不回传明文；
- **最小可见**：机密仅 server 进程在执行动作时解密，日志/state/错误信息不落明文；
- alg/密钥版本：`secret_store` 统一入口（`Encrypt/Decrypt`），全项目禁止散落手写 crypto。

## 4. 订阅令牌隔离（P0）

- **sub token ≠ 用户密码**：独立随机 256 位（复用 `randomToken`），泄露只影响订阅可见性，不触及账号管理面；
- 订阅端点只读、可独立重置（重置后旧链接失效）；
- 限频：订阅端点按 token 限频（防枚举），命中限频记日志；
- 最小化：订阅响应不含管理字段（成本/内部 IP 等），只含节点连接信息。

## 5. 其他面

| 面 | 口径 |
| --- | --- |
| 内部接口 | `/api/internal/*` 只监听本机/内网（回执类），不走公网 |
| servify 上下文 | 只读接口白名单下发（套餐/流量/订单），凭据类字段永不下发（见《用户面板运营设计》§4） |
| 支付回调 | 验签（Provider.Verify）+ 幂等（对齐支付设计 §4） |
| 备份文件 | 备份含机密表 → 备份文件同样加密或仅存面板机（见《面板可用性设计》） |

## 6. 分期

| 阶段 | 内容 |
| --- | --- |
| P0 | 订阅令牌隔离与限频；随机令牌口径统一（节点/订阅/卡密同源 `randomToken`） |
| P1 | 管理员登录+2FA+防爆破+登录审计；节点令牌轮换；secret_store 加密面；mTLS 生命周期管理 |
| P2 | CA 自动化签发编排（对齐 BR-4）；安全审计报表 |
