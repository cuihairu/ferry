# 用户面板运营设计（用户面板篇）

panel 侧运营能力：通知、订单、促销、客服。原则：站内信为主、账目与支付三账对得上、外部投递统一经 Herald（见《告警通道设计》）；触达与断联容灾独立成篇（《用户触达设计》）。

## 1. 通知中心（P1）

### 1.1 类型与形态

| 类型 | 触发 | 默认通道 |
| --- | --- | --- |
| 公告 | dash 发布（全员/分组） | 站内信（RSS 输出见《用户触达设计》） |
| 到期提醒 | 定时扫描（到期前 N 天） | 站内信 + 邮件/TG（用户偏好） |
| 流量预警 | 用量 ≥ 阈值（默认 80%） | 站内信 + 用户偏好通道 |
| 系统通知 | 订单完成/兑换成功/维护 | 站内信 |

- **站内信为主**：`notifications` 表 + 未读数 + 列表页，不依赖外部通道可用。
- 通道（邮件/TG）可配：默认关，用户开了才发；经 Herald 分发。
- 用户**提醒偏好**：类型 × 通道开关 + 预警阈值，panel 设置页可改。

## 2. 订单中心（随支付批）

- **记录范围**：购买记录（PaymentOrder 列表）+ 卡密兑换记录（provider=card 的订单/流水），同一列表按来源筛选。
- **状态**：待付 / 已完成 / 已退款（`pending` / `paid` / `refunded`——现有状态枚举补 `refunded`，退款动作 dash 侧做）。
- **订单详情**：套餐、金额、时长/流量（对应发放记录的 grant 快照）、支付时间、订单号。
- 与管理面打通：dash 订单管理/对账视图（PAY-9）是同一批数据的管理视角。

## 3. 优惠促销（P2）

| 能力 | 说明 |
| --- | --- |
| 优惠码 | 满减 / 折扣 / 指定套餐；`coupons` 表（code、类型、值、适用范围、起止、总量与每用户限次） |
| 限时活动 | `campaigns` 表（起止时间、适用范围、折扣规则），dash 配置 |
| 新用户首单折扣 | 活动规则的内建类型（首单判定=无历史已付订单） |
| 续费折扣 | 活动规则的内建类型（命中已有用户再次下单） |

- **dash 配置**：起止时间、适用范围（套餐/全站）、用量限制（总量/每用户）。
- **panel 展示与核销**：活动位展示（进行中/即将开始）；下单时校验并原子扣减用量，重复提交不双扣。
- **账目口径**：订单记 `list_amount`（原价）+ `amount_cents`（实付）+ 优惠快照（码/活动/抵扣额）；流水=实付、发放=获得权益——优惠后实付入账与支付三账对得上。
- 与分销折扣的叠加规则见《计划扩充设计》§3.3（不叠加取优）。

## 4. 客服：集成 servify（P2）

- **选型**：站内客服集成 **servify**（自家开源智能客服：AI 首答、人工接管、工单闭环），不自研客服。
- **入口**：panel 嵌客服入口（servify 组件 / iframe / SDK，以实际对接面为准）；
- **工单上下文**：客服侧可见用户套餐/流量/订单状态——**只读视图**，走 ferry 服务端接口下发，不泄凭据（令牌/密码类不出现）；
- **互补**：人工接管后的会话跟进与用户触达体系（TG/邮件）互为补充，工单结果回写站内通知；
- **部署形态**：servify 独立部署，ferry 只配对接地址（面板配置项）。

## 5. 数据模型

```sql
-- 站内通知
CREATE TABLE notifications (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id    INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    kind       TEXT    NOT NULL,        -- notice/expiring/quota/system
    title      TEXT    NOT NULL,
    body       TEXT    NOT NULL DEFAULT '',
    read_at    DATETIME,
    created_at DATETIME NOT NULL
);
CREATE INDEX idx_notifications_user ON notifications(user_id, created_at);

-- 优惠码与活动
CREATE TABLE coupons (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    code        TEXT    NOT NULL UNIQUE,
    kind        TEXT    NOT NULL,       -- cut 减额 / pct 折扣
    value       INTEGER NOT NULL,       -- 分 或 基点(10000=不打折)
    scope       TEXT    NOT NULL,       -- all / 指定套餐
    min_amount  INTEGER NOT NULL DEFAULT 0,
    starts_at   DATETIME,
    ends_at     DATETIME,
    total       INTEGER NOT NULL DEFAULT 0,   -- 0=不限
    per_user    INTEGER NOT NULL DEFAULT 1,
    used        INTEGER NOT NULL DEFAULT 0,
    created_at  DATETIME NOT NULL
);

CREATE TABLE campaigns (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT    NOT NULL,
    kind        TEXT    NOT NULL,       -- first_order 首单 / renew 续费 / timed 限时
    rules       TEXT    NOT NULL,       -- 折扣规则 JSON（适用范围/折扣值）
    starts_at   DATETIME NOT NULL,
    ends_at     DATETIME NOT NULL,
    enabled     INTEGER NOT NULL DEFAULT 1,
    created_at  DATETIME NOT NULL
);

-- 订单补优惠与状态位（PaymentOrder 既有列上扩展）
-- list_amount_cents  INTEGER NOT NULL DEFAULT 0,  -- 原价
-- promo_snapshot     TEXT,                        -- 优惠码/活动/抵扣快照
-- status 增补 'refunded'（待付/已完成/已退款）
```

## 6. 分期

| 阶段 | 内容 |
| --- | --- |
| 随支付批（P0/P1） | 订单中心：兑换与购买记录、订单详情与状态（含 refunded） |
| P1 | 通知中心（站内信+偏好） |
| P2 | 优惠促销（优惠码/限时活动/首单续费折扣+账目打通）、servify 客服集成 |
