## 抽象层概念

| 术语 | 英文 | 定义 | file:line |
| --- | --- | --- | --- |
| 服务装配层 | Service Assembly | 二进制入口：读环境变量配置、解密钥门禁、开数据库、起全部后台循环、起 HTTP 监听。层=职责（装配与生命周期），不是目录名。 | `server/cmd/ferry/main.go:68` |
| 配置层 | Config | 服务运行参数集中定义与读取：环境变量（`FERRY_*`）→ 默认值；分 server 侧与 agent 侧两份独立 schema。 | `server/internal/config/config.go:146`；`agent/internal/config/config.go:63` |
| 密钥门禁层 | Key Gate | 签名/加密密钥的初始化定值：显式配置 > 密钥文件 > 生成并持久化；生产缺钥/弱钥拒绝启动。 | `server/internal/keyinit/keyinit.go:48` |
| 存储层 | Storage | GORM 三方言（sqlite/postgres/mysql）连接与 AutoMigrate；全部业务状态落关系库，无 Redis。 | `server/internal/storage/storage.go:27` |
| 数据模型层 | Data Model | 领域实体与跨层载荷：GORM 模型（storage/models.go）与请求/响应载荷（model/model.go）分离。 | `server/internal/storage/models.go:5`；`server/internal/model/model.go:1` |
| 协议契约层 | Protocol Contract | agent↔panel 消息契约：WebSocket + JSON 封装（Envelope），版本号、消息类型、载荷结构，双方共用包。 | `packages/agentproto/envelope.go:1`；`packages/agentproto/messages.go:1` |
| 连接枢纽层 | Connection Hub | agent 在线连接的进程内内存表（map[nodeID]*Conn）+ 请求应答关联（waiters）；仅内存，不持久化。 | `server/internal/agenthub/hub.go:66` |
| HTTP 路由层 | HTTP Routing | gin 引擎挂载全部端点，分鉴权组（管理面/公开面/代理面/管理员面），中间件链统一。 | `server/internal/handler/router.go:53` |
| 接口处理器层 | Interface Handler | 每个资源的 HTTP 处理器：解析载荷、校验、调领域服务、回写 JSON；挂在 Handler 结构体上。 | `server/internal/handler/node.go`；`server/internal/handler/panel.go:213` |
| 领域服务层 | Domain Service | 无 HTTP 依赖的业务逻辑包（alloc/pool/monitor/recovery/provision/…），周期循环 + 判定/执行函数。 | `server/internal/alloc/alloc.go:395`；`server/internal/pool/pool.go:74` |
| 采集与画像层 | Collection & Profiling | agent 心跳/流量/探测/进程状态上报 → 落库；节点画像（元数据/负载/成本/健康）由上报驱动。 | `server/internal/handler/agentws.go:51`；`server/internal/aggregate/aggregate.go:65` |
| 决策与执行层 | Decision & Execution | 落地分配、入口摘挂、封禁恢复、供给/证书/DNS 编排：读画像→决策→留痕→触发下发。 | `server/internal/alloc/alloc.go:437`；`server/internal/recovery/recovery.go:107` |
| 下行推送层 | Downstream Push | 面板→agent 配置下发/换线重指：落库 pending → agenthub 等 ack → 置 applied/failed；复用 config.push 链路。 | `server/internal/relaypush/relaypush.go:69` |
| 事件外发层 | Event Egress | 事件 outbox：事件落库即返回，异步重试投 Herald；未接 Herald 只落库站内可见；通知 webhook 位。 | `server/internal/herald/herald.go`；`server/internal/notify/notify.go` |
| 安全与限流层 | Security & Rate Limit | 机密 AES-256-GCM 加密统一入口（R24）；内存滑动窗口限流（PAY-5）；JWT 鉴权中间件；审计中间件。 | `server/internal/secret/secret.go:28`；`server/internal/ratelimit/limiter.go:37`；`server/internal/handler/apitoken.go:92` |
| 运维与恢复层 | Ops & Recovery | 备份（VACUUM INTO+S3 外发）、面板主从同步、操作审计清扫、运行日志环形缓冲、客服对接。 | `server/internal/backup/backup.go:153`；`server/internal/standby/standby.go:151`；`server/internal/audit/audit.go:30` |
| Agent 核心层 | Agent Core | agent 常驻最小集：连接/心跳、进程监管、配置下发/回滚、流量/负载上报（目标 ≤10MB）。 | `agent/internal/app/app.go:74`；`agent/internal/link/link.go:62` |
| Agent 角色层 | Agent Role | 按节点 role 装配的独立进程组件：probe/relay/speedtest/tunnel；与核心只经本机配置文件/spool 交互。 | `agent/internal/roles/roles.go:1`；`agent/internal/roles/relay/relay.go:41` |
| 隧道传输层 | Tunnel Transport | 传输插件抽象：tls-camo/quic/ws-tls/ssh，Dial 出站 + 应用层心跳；注册表按名构造。 | `agent/internal/tunnel/tunnel.go:16` |
| 订阅渲染层 | Subscription Render | 节点配置 → v2ray/clash(mihomo)/sing-box 订阅内容；入口顺序按探测 RTT 重排+轮换。 | `server/internal/sub/links.go`；`server/internal/sub/rotate.go:21` |
| 支付渠道层 | Payment Channel | 收款 Provider 契约与注册表（card/epusdt/wechat/alipay）；渠道插件 init 自注册，验签在渠道内。 | `packages/payment/provider.go:13`；`payments/epusdt/epusdt.go:64` |
| 成本参考层 | Cost Reference | 参考牌价来源插件位（costref.Source）；手录成本唯一权威，参考价只提示不改价。 | `packages/costref/costref.go:25`；`server/internal/cost/ref.go:25` |
| 前端管理面 | Admin Frontend | Vue3 + Element Plus 管理台（dash）：路由级视图 + api.ts 客户端（Bearer JWT/代理令牌）。 | `dash/src/router.ts:7`；`dash/src/api.ts:16` |
| 前端用户面 | User Frontend | Vue3 用户面板（panel）：登录/概览/兑换/订单/通知；api.ts 客户端携带订阅令牌。 | `panel/src/router.ts:5`；`panel/src/api.ts:13` |
